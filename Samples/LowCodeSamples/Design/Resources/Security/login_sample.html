ログインの方式

  • ID とパスワード
  • Microsoft (Entra ID)・Google・Amazon Cognito のアカウント
  • OpenID Connect に対応したほかの認証基盤 (Keycloak・Auth0 など)
  • 独自の認証基盤も、部品を足すだけで追加できます

二要素認証

  • 認証アプリ (Google Authenticator・Microsoft Authenticator など) の 6 桁コード
  • メールで届くワンタイムコード (利用者側の登録が要りません)

運用に合わせて

  • 外部のアカウントは、サーバーの設定に書くだけでログイン画面にボタンが並びます
  • パスワードを使わず、外部のアカウントだけでログインする構成にもできます
  • 外部のアカウントでログインできるのは、既定ではユーザー一覧に登録済みの人だけです。退職者などはユーザーを無効にすればログインできなくなります
  • スマートフォンのアプリ (MAUI) も、同じ仕組みでログインできます
  • どの方式でログインしても、画面やデータの権限の設定は同じものが効きます

ログイン画面の見た目 (ロゴ・アプリ名・色) は HTML で自由に変えられます。このデモサイトはログインなしで見られる構成のため、この画面は見本として置いています。
