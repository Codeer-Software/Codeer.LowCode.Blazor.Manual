Jobs/CloseOrdersJob.cs (例: 締め処理)

public class CloseOrdersJob : IJob
{
    public string Name => "CloseOrders";

    public async Task<string?> RunAsync(DataService data, string[] args)
    {
        //画面で作った「受注」モジュールをそのまま検索
        var page = await data.ModuleDataIO.GetListAsync(
            new SearchCondition("Order"), 0);

        //... 締めの処理。保存も同じモジュールで
        //(権限・編集履歴などは画面から保存したときと同じ)

        return $"{page.TotalCount} 件を締めました";
    }
}
REM 起動 (タスクスケジューラ・Azure WebJobs など)
dotnet LowCodeApp.Server.dll job CloseOrders

作り方

  • ジョブは C# のクラスを 1 つ書くだけ (IJob を実装)。登録は要りません
  • デザイナで作ったモジュールを、モジュール名・フィールド名でそのまま読み書きできます
  • 権限・保存時の処理・編集履歴など、画面から保存したときと同じ仕組みが働きます
  • Web サーバーと同じプログラム・同じ設定で動くので、バッチ用のプロジェクトや接続設定を別に用意する必要はありません

起動の仕方

  • 定期実行: Windows のタスクスケジューラ、Azure App Service の WebJobs など
  • 画面から: ジョブトリガー (ボタン) で、画面の内容を渡して実行。終わるまで待って結果を通知する・起動だけして戻る、のどちらも選べます

※ このデモサイトではジョブは動かしていません。ジョブの仕組みはアプリのテンプレートにソースコードとして含まれています。詳しくはマニュアルの バッチ処理（ジョブ） を参照してください。
