AI

業務データに AI を組み合わせる機能です。

AI-OCR

名刺・請求書・レシートの画像から、項目を読み取って入力します。

AI チャット

「得意先別の売上トップ 5 は？」と聞くと、DB を調べて表やグラフで答えます。

権限つき AI チャット

画面と同じ権限でデータを読むので、見せてはいけないデータは答えません。

意味検索

言葉が一致しなくても、意味の近いデータを探します。

社内文書の検索

Word・Excel・PDF などの添付ファイルの中身まで、意味とキーワードで探します。

業務でよく使う機能

承認・集計・履歴・帳票など、業務アプリに必要な仕組みを部品として用意しています。

編集履歴

誰がいつ何を変えたかを記録。版の差分確認と復元ができます。

タグ

レコードにタグを付けて分類。候補から選べて、タグで絞り込めます。

承認フロー

申請・承認・却下・差し戻し。金額で経路が変わる多段承認や合議にも対応。

Excel 帳票・PDF

Excel で作ったテンプレートに画面のデータを流し込み、PDF を作ります。

メール一斉送信

名簿の宛先ごとに差し込みしたメールを送信。送信前のプレビュー付き。

クロス集計

担当者 × 四半期などの集計表。行・列の組み替えも画面から。

集計チャート

DB で集計してグラフに。件数が増えても軽く動きます。

SQL での集計

SQL を書いて、その結果を画面に表示。集計期間などの条件は画面から渡せます。

セキュリティ

外部のアカウント (Microsoft・Google など) でのログインや二要素認証、ユーザーごとの権限、操作の記録 (監査ログ) など、業務システムに求められる仕組みです。

認証

ID・パスワードに加え、Microsoft・Google・Amazon Cognito のアカウントや二要素認証でログイン。

認可 (権限)

アプリ・ページフレーム・モジュール・フィールドごとに、読める・書けるユーザーを設定。判定はサーバーで行います。

監査ログ

誰が・いつ・どこから・何をしたかを自動で記録。ログインの失敗や権限による拒否も残ります。

標準機能

入力部品・一覧・レイアウトを並べて DB につなぐだけで、画面ができあがります。動きはスクリプトで足せます。

入力部品

テキスト・数値・日付・選択・ファイルなどの標準部品。連動入力・入力チェック・自動計算・確認メッセージなどの便利機能も。

一覧

複数行・詳細・タイル・分割・その場で編集の 5 つの見せ方。

レイアウト

入力フォーム・レスポンシブ・タブ・ウィザード・ダイアログ・キャンバスなど 11 の型。

DB 連携

テーブルにつなぐだけで一覧・検索・登録・更新。SQL のクエリも使えます。

スクリプト

C# とほぼ同じ書き方。入力補完とデバッガ付き。

拡張部品

カレンダーやガントチャートなど、業務でよく使う高機能な部品です。ツールボックスから置くだけで使えます。

カレンダー

月・週・日の表示。クリックで予定の追加・編集。

ガントチャート

ドラッグで期間を変更。タスク間の依存関係も表示。

タスクボード

カンバン形式。カードをドラッグしてステータスを変更。

画像マーカー

図面や写真の上にピンを置いて、情報をひも付けます。

リッチテキスト

太字・色・サイズ・リンクなど、書式付きの文章を入力・保存。

Markdown

Markdown で入力し、プレビューで見え方を確認。

QR コード

入力した URL や文字列を、その場で QR コードにして表示。

グラフ

棒・折れ線・面・ドーナツ・ヒートマップなど。

プロコード・デザイン

ノーコードで足りないところは C# で作り込めます。見た目は CSS で変えられます。

プロコード

Blazor のコンポーネントや C# のコードを画面に組み込めます。

バッチ処理

通常の .NET (C#) で書き、作ったモジュールをそのまま使えます。定期実行や画面のボタンから起動。

デザインの切り替え

CSS で見た目を変えられます。Bootstrap・Fluent・Material など。

活用例

部品を組み合わせて作った、画面やアプリの例です。

工場ダッシュボード

稼働率・不良率などを 1 画面に。

プロジェクト管理

プロジェクト・タスク・メンバーの管理と進捗の見える化。

営業支援 (SFA)

商談・活動履歴の管理と、要対応の商談の抽出。

在庫管理

入庫・出庫・棚卸し・発注と、要発注品の抽出。

ハンディー端末

現場の小さな画面向けのレイアウト。タブレット向けもあります。
