## ライセンス種別

各ライセンスの価格については[ホームページ](https://www.codeer.co.jp/LowCode#)をご確認ください。

### 開発時に必要なライセンス
#### 1.開発ライセンス
開発時に必要になります。  
1部署最大30台のマシンで利用可能です。  
開発/テスト用にWebサーバーで利用することもできます。

### 運用時に必要なライセンス
#### 1.サーバーライセンス（シングルテナント用）
Webアプリ利用時に必要です。（※クライアントサーバーアプリでは不要です）  
オンプレミスおよびクラウドのIaaS環境では1サーバーごとにライセンスが必要です。  
クラウドのPaaS環境（例：AppService）では1ドメインごとにライセンスが必要です。  
ライセンスはユーザー数に依存しません。

※マルチテナントやその他特殊な利用形態については特別契約にて柔軟に対応いたします。 お気軽にご相談ください。

#### 2.クライアントライセンス
WinForm / WPF で作成するクライアントサーバーアプリ用です。（※Webアプリでは必要ありません）  
最大100台まで利用可能です。

#### 3.メンテナンスライセンス
Designerを使って設定の変更だけを実行できるライセンスです。  
1台のマシンで利用可能です。  
メンテナンス時にテスト用途でそのマシンでWebアプリを起動することも可能です。

## ライセンス種別ごとにできること

Codeer.LowCode.Blazor 1.3.46 / Designer 1.3.43 以降では、登録されているライセンスの種別で次の操作が制限されます。

| ライセンス | ホストアプリのビルド | Designer での編集・保存 | Designer からの送信 | Designer の CLI (Claude Code 連携) |
|---|---|---|---|---|
| トライアル (30 日) | ○ | ○ | ○ | ○ |
| 開発 | ○ | ○ | ○ | ○ |
| メンテナンス | × | ○ | ○ | ○ |
| サーバー | × | × (閲覧と送信のみ) | ○ | × |
| クライアント | × | × (閲覧と送信のみ) | ○ | × |

### ホストアプリのビルド

Codeer.LowCode.Blazor を参照するプロジェクトは、開発ライセンスかトライアルがあるマシンでだけビルドできます。それ以外のマシンではビルドがエラー `CLB0001` で止まります。

- ライセンスもトライアルも無い新しいマシンでは、最初のビルドでトライアルが自動的に登録されます (ライセンスサーバーへの接続が必要です。登録に 10 秒ほどかかります)。
- トライアル中のビルドはライセンスサーバーに接続できる必要があります (結果は 1 時間ほど保持されます)。
- トライアルが終了しているか、サーバー / クライアント / メンテナンスのライセンスが登録されているマシンではビルドできません。開発ライセンスを登録してください。
- CI (ビルドサーバー) でビルドする場合は、そのマシンにも開発ライセンスを登録してください。

### Designer と CLI

- サーバーライセンスまたはクライアントライセンスのマシンでは、Designer は閲覧と送信 (デプロイ) だけができ、変更の保存・プロジェクトの作成・ツリーの操作・外部拡張のメニューは使えません。画面の右上に「閲覧と送信のみ」と表示されます。
- Designer の CLI (headless サブコマンド。Claude Code ワークスペースが使うもの) は、開発・メンテナンス・トライアルのいずれかのライセンスがあるときだけ動きます。
- ライセンス登録用のアプリ (LicenseRegister / LicenseRegisterCli) はライセンスが無くてもビルドできます。

## ライセンス登録方法

開発ライセンスとサーバーライセンスはDesignerから登録することが可能です。

#### 1.オンライン
登録方法、解除方法は下記をご覧ください。
- [登録](license_online_registration.md)
- [解除](license_online_cancellation.md)

WEBに接続できない環境の場合はオフラインで登録することが可能です。

#### 2.オフライン（WEB経由）
登録方法、解除方法は下記をご覧ください。
- [登録](license_web_registration.md)
