# フォーカス制御

Enter キーや Tab キーで入力欄を順に移動させる機能です。キーボード中心で入力する業務画面（伝票入力など）で、マウスに持ち替えずに入力を続けられるようにします。

スクリプトを書かなくても、レイアウトのプロパティを設定するだけで動作します。

---

## 設定の流れ

1. 詳細・一覧・検索のいずれかのレイアウトを選択し、プロパティパネルの **フォーカス制御** カテゴリで **FocusControlMode**（フォーカス制御モード）を `Enter` / `Tab` / `EnterAndTab` のいずれかにする
2. 必要に応じて、画面を開いたときにフォーカスを当てる Field（**InitialFocusField**）や、末尾で先頭に戻るか（**IsFocusWrap**）を設定する
3. 移動順を変えたい Field・飛ばしたい Field があれば、Field 側のプロパティ（[下記](#field-側のプロパティ)）で調整する

---

## レイアウト側のプロパティ

| プロパティ | 設定できるレイアウト | 説明 |
|---|---|---|
| **FocusControlMode**（フォーカス制御モード） | 詳細 / 一覧 / 検索 | どのキーでフォーカスを移動させるか（[下記](#フォーカス制御モード)） |
| **IsFocusWrap**（フォーカスを循環する） | 詳細 / 一覧 / 検索 | オンにすると、最後の Field から次へ進んだときに先頭の Field に戻る。オフ（既定）のときは、最後の Field からはブラウザ標準の動作に戻る（Tab ならページ上の次の要素へ移動し、Enter なら何もしない） |
| **InitialFocusField**（初期フォーカスフィールド） | 詳細 | 画面を開いたときに最初にフォーカスを当てる Field。詳細ページ・ダイアログとして開いたレイアウトで有効（ModuleField などに埋め込まれたレイアウトでは使われない） |

### フォーカス制御モード

| 値 | 表示名 | 動作 |
|---|---|---|
| `Inherit` | 継承 | 親のレイアウトの設定を引き継ぐ（既定） |
| `None` | なし | フォーカス制御をしない（ブラウザ標準の動作）。親が有効でも、このレイアウトの中では無効にする |
| `Enter` | Enter | Enter で次へ、Shift+Enter で前へ移動する。Tab はブラウザ標準の動作 |
| `Tab` | Tab | Tab で次へ、Shift+Tab で前へ移動する。Enter は標準の動作のまま |
| `EnterAndTab` | EnterとTab | Enter と Tab の両方で移動する |

`Inherit` は入れ子のときに意味を持ちます。

- 詳細ページ・ダイアログ・一覧ページ・検索のように画面の一番外側のレイアウトでは、`Inherit` は `None`（無効）と同じです。フォーカス制御を使うには明示的にモードを設定してください
- ModuleField に表示する子モジュールの詳細レイアウトや、ListField / DetailList / TileList の行のレイアウトが `Inherit` のときは、配置先のレイアウトのモードが使われます。親で有効にすれば中の入力欄まで続けて移動できます
- 一覧ページ（ListField を置いたページ）では、一覧レイアウト（DetailList / TileList の場合は行の詳細レイアウト）にモードを設定します

---

## 移動の順番

- 基本はレイアウトに**配置した順番**です。ModuleField や ListField の中の入力欄は、その位置で中身を順にたどります
- ListField（テーブル形式）では、各行のセルを列の並び順にたどり、次の行へ進みます
- 検索レイアウトでは、最後の Field の次に標準の検索ボタン・クリアボタンに移動します。検索ボタン上で Enter を押すと検索が実行されます
- 次の Field は飛ばされます
  - **IsFocusSkip**（フォーカス遷移スキップ）をオンにした Field
  - 非表示・無効・読み取り専用の Field
  - Label など、入力欄を持たない Field
- 日付と時刻のように 1 つの Field に複数の入力欄がある場合は、Field の中の入力欄を順に移動してから次の Field へ進みます
- 複数行の TextField（テキストエリア）、ボタン、リンクの上では Enter は通常の動作（改行・クリック）になります
- 日本語入力の変換中の Enter では移動しません
- 移動先の入力欄の文字は全選択された状態になります

TextField の **AutoTab**（自動タブ(最大桁で次へ)）をオンにすると、`MaxLength` まで入力した時点で自動的に次の入力欄へ移動します。これもフォーカス制御モードが有効なレイアウトでだけ働きます。

## Field 側のプロパティ

各 Field のプロパティパネルの **フォーカス制御（フォーカス制御モード有効時のみ）** カテゴリで設定します。フォーカス制御モードが有効なレイアウトに置いたときだけ働きます。

| プロパティ | 説明 |
|---|---|
| **IsFocusSkip**（フォーカス遷移スキップ） | オンにすると、Enter / Tab での移動先から外す（マウスでのクリックではフォーカスできる）。ModuleField / ListField に設定すると、中の入力欄もまとめて外れる |
| **NextFocusField**（次のフォーカス先） | この Field の次に移動する Field を指定する。空なら配置順の次。途中だけ順番を変えたいときは、順番が変わり始める Field にだけ設定すればよい。Shift+Enter / Shift+Tab で戻るときは、自分を次のフォーカス先に指定している Field に戻る |
| **OnFocusMoving**（フォーカス遷移イベント） | この Field から移動する直前に呼ばれるスクリプト。`true` を返すと予定どおり移動し、`false` を返すと移動しない |

### OnFocusMoving

引数は、押されたキー（`"Enter"` / `"Tab"`。AutoTab による移動では `"AutoTab"`）、Shift キーが押されているか、移動する予定の Field 名です。

入力内容によって移動先を変えたい場合は、スクリプトの中で移動先の Field の `Focus()` を呼んでから `false` を返します。

```csharp
bool Code_OnFocusMoving(string key, bool shift, string defaultTarget)
{
    // 区分が「その他」以外のときは備考欄を飛ばして金額へ移動する
    if (!shift && Category.Value != "その他")
    {
        Amount.Focus();
        return false;
    }
    return true;
}
```

## Grid の OnKeyDown からの移行

Grid の `OnKeyDown` イベントは非推奨です。Enter キーで次の入力欄へ移動するといった処理をスクリプトで書いていた場合は、このフォーカス制御に置き換えてください（[レイアウト - OnKeyDown イベント](layout.md#onkeydown-イベント)）。
